# UI / UX Guidelines

## Arah visual
- Minimal, profesional, bersih, dan mudah digunakan.
- Latar putih atau abu-abu sangat muda.
- AsaTech blue sebagai warna aksen; tentukan satu warna utama dari identitas brand yang tersedia.
- Font Inter atau sans-serif sistem.
- Tidak menggunakan glassmorphism.
- Hindari gradient dekoratif, animasi berlebihan, dan elemen yang tidak membantu pekerjaan.

## Layout
- Sidebar navigasi di desktop.
- Topbar berisi judul halaman, breadcrumb seperlunya, dan menu akun.
- Konten utama memakai lebar yang nyaman dibaca.
- Pada layar kecil, sidebar berubah menjadi drawer/menu ringkas.
- Gunakan tabel untuk data administratif dan form yang berlabel jelas.

## Navigasi
- Dashboard
- Data Barang
- Kategori
- Lokasi
- Barang Masuk
- Barang Keluar
- Riwayat Transaksi
- Laporan
- Manajemen Pengguna (Admin)
- Profil / Logout

## Komponen
Buat komponen Blade reusable:
- button primary/secondary/danger
- input, select, textarea
- form error
- status badge
- table dan empty state
- pagination
- confirmation modal
- flash success/error message

## UX rules
- Label field harus jelas dan selalu terlihat.
- Tampilkan validasi dekat field terkait.
- Konfirmasi tindakan yang berdampak besar.
- Jangan hanya mengandalkan warna untuk status.
- Tampilkan satuan pada kuantitas.
- Tampilkan stok tersedia saat memilih produk untuk transaksi keluar.
- Form transaksi multi-item harus mudah menambah/menghapus baris.
- Sediakan empty state yang menjelaskan tindakan berikutnya.
- Hindari angka contoh yang terlihat seperti data perusahaan nyata.
